# 量潮商务服务黄页 — 设计

## 定位

服务黄页：展示没有产品形态的定制服务与解决方案（数据服务、咨询、定制开发），与 qtproduct 构成产品与服务双黄页。

核心问题只有一个：**客户怎么知道"你们能做什么、跟我有什么关系、怎么收费"？**

设计输入：`docs/dev-guide/index.md`（PRD）、`data/journal/`（商务拓展日志）、`data/profile/`（业务档案）。

## 首页

### Hero

一句话说明服务黄页是什么，附服务类型锚点。

> 量潮商务：服务黄页。
> 展示没有产品形态的定制服务与解决方案。

锚点：`数据服务 · 咨询 · 定制开发`

### 服务列表

首页核心区块。展示全部服务条目：类型标签 + 标题 + 适用场景，附"全部服务 →"链接到 `/services`。

### 定价模式

公开收费方式的说明：项目制报价、按量处理费、存储年费、咨询按次。公开定价即公开商业模型，降低客户的评估与信任成本。

### 联系

GitHub / 邮件，无表单；询盘经联系渠道进入商务云流程（澄清需求 → 报价 → 合同）。

## 服务页 `/services`

按类型筛选（`全部 / 数据服务 / 咨询 / 定制开发`），列表展示类型、标题、场景、定价模式。

## 服务详情 `/services/:slug`

- 适用场景
- 交付物
- 定价模式
- 询盘说明（进入商务云五步流程）

## 演进方向

1. **案例库**：按行业/场景组织过往合作案例，形成"服务 → 案例"信任证据链；
2. **询盘与商务云打通**：询盘自动生成需求澄清会话，报价单直接引用黄页条目；
3. **导流机制**：服务条目挂接导流目标（课堂、产品黄页、数据服务），低门槛条目作为增长漏斗入口；
4. **供应链池展示**：服务条目与执行方/合作方挂钩，支撑三方平台。
