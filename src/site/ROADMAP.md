# ROADMAP

量潮商务服务黄页（qtbusiness-site）。

## 目标

实现 `docs/dev-guide/index.md` 的设计：服务黄页——展示没有产品形态的定制服务与解决方案（数据服务、咨询、定制开发），与 qtproduct 构成产品与服务双黄页。核心问题：**客户怎么知道"你们能做什么、跟我有什么关系、怎么收费"？**

## 当前状态

- 首页：Hero + 服务列表 + 定价模式（源自 profile）+ 联系
- 服务页：`全部 / 数据服务 / 咨询 / 定制开发 / 招聘` 筛选
- 详情页：适用场景 / 交付物 / 定价 / 来源业务 / 询盘说明
- 数据：`data/services.ts` 静态服务清单，条目与定价源自 `data/profile/`（qtdata / qtcloud / qtrecurit）

## 阶段 1：数据层扩展

| 任务 | 说明 |
|------|------|
| 扩展 `services.ts` | 服务条目补充；新增 `cases` 字段（案例：行业 / 场景 / 问题 / 做法 / 结果） |
| 新增 `data/cases.ts` | 案例库：按行业/场景组织，"我们懂这一类客户"（宣传册逻辑） |

## 阶段 2：案例与相关性

| 任务 | 说明 |
|------|------|
| 案例展示 | 首页/详情页展示相关案例，形成"服务 → 案例"信任证据链 |
| 按场景浏览 | 客户按行业/问题类型找服务，直接回答"这跟我有什么关系" |

## 阶段 3：询盘与导流

| 任务 | 说明 |
|------|------|
| 询盘入口 | 联系表单或邮件链接，携带服务与场景信息；与商务云打通（询盘 → 需求澄清） |
| 导流机制 | 服务条目挂接导流目标（课堂、产品黄页、数据服务），低门槛条目作为增长漏斗入口 |

## 阶段 4：数据自动化（后期）
